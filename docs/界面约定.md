## 按钮（用户 2026-10-12）

1. **一律用主样式**：`Appearance="Primary"`，与执行页的「启动试验」一致；不要用 `Secondary`。
2. **一律配图标**：`Icon="{ui:SymbolIcon <Name>24}"`。已用到的对应关系：

   | 按钮 | 图标 |
   | --- | --- |
   | 启动试验 / 停止试验 | `Play24` / `Stop24`（随运行状态切换） |
   | 有效性计算 | `CheckmarkCircle24` |
   | 新建试验 / 新建试样 | `Add24` |
   | 编辑试样 | `Edit24` |
   | 删除试样 | `Delete24` |
   | 试验参数 | `Settings24` |
   | 打印报表 | `Print24` |
   | 历史数据 | `History24` |
   | 清空信息 | `Broom24` |
   | 数据流（占位，未实现） | `DataTrending24` |

3. **图标名先验证再写**：WPF-UI 的图标是 `SymbolRegular` 枚举，名字写错运行期不会报错、只是**静默没有图标**。用下面这条命令确认（示例查 Play24）：

   ```powershell
   rg -a -o -N "Play24" "C:\Users\ChenJie\.nuget\packages\wpf-ui\4.3.0\lib\net10.0-windows7.0\Wpf.Ui.dll"
   ```

   路径里的版本号取自当前引用的 WPF-UI 包版本。
4. **按钮内容是复合元素时补 `AutomationProperties.Name`**：把按钮内容换成 `StackPanel`（图标 + 文字）后，WPF 默认的自动化名称取不到文字，UIA 与读屏都会失明。示例（启动/停止按钮）：

   ```xml
   AutomationProperties.Name="{Binding ViewModel.StartStopText, Mode=OneWay}"
   ```

5. 未实现的占位按钮保持 `IsEnabled="False"` 并给 `ToolTip`（外观同样用主样式，禁用态自带变灰）。

## 列表与页面滚动（用户 2026-10-12）

- **滚动只发生在页内列表上，页面本身不滚**。页面宿（WPF-UI 的 `DynamicScrollViewer`）按**无限高度**量内容，
  页内 Grid 的 `*` 行会退化成"按内容取高"——列表条目一多就把整页撑高，滚动落到外层宿主上。
- 对策：页面构造函数末尾调用 `PageViewportFitter.Attach(this);`
  （`Views\PageViewportFitter.cs`）——它把页面 `MaxHeight` 对齐到外层滚动容器的视口高度，
  `*` 行于是拿到真实可见高度，列表在页内自己滚。**凡是页内有 `*` 行 + 列表的新页面都要加这一句。**
  已加：试验执行页、试验单页、历史数据页。
- 列表**不要靠"刷新"按钮才加载**：切到该模式 / 进页面时自动查询（现役 `TSelectBendingTestMainForm.FormCreate`
  同样打开窗体即 `qryGetSheetInfo.Open`）；「刷新列表」只当手动再查用。
  已做：试验单页（切到「选择已有」即查）、**历史数据页（进页面即查，2026-10-13 用户提出）**、
  参数配置页 / 试样信息页（`OnNavigatedTo` 重新读库）。做法统一：`ViewModelBase.OnNavigatedTo()` 里发起查询。
- **试验单列表按创建时间倒序**（最新在最上，用户 2026-10-13 要求）：排序落在数据层
  `TestSheetService.QueryAsync` 的 `ORDER BY CreatedOn DESC, SheetID DESC`，试验单页与历史页共用
  —— 两处顺序一致。`CreatedOn` 是 `yyyy-MM-dd HH:mm:ss` 定长文本，文本序 = 时间序。

## 曲线标注（用户 2026-10-13）

- **时机**：只在该试件**完成后**标注（过程中不画）；新一轮开始随曲线一起清掉。
- **四处内容**：

  | 标注 | 画法 | 取值 |
  | --- | --- | --- |
  | 峰值点 | 橙红实心圆 + 文字 `峰值 {荷载} kN / {挠度} mm` | 曲线里荷载最大的点 |
  | 修正直线 y = k·x + b | 主题文字色**虚线**，横跨整条曲线、下端交 X 轴 | 判定器拟合结果 |
  | 修正原点 | 空心圆 + 文字 `修正原点 {x} mm` | 直线与 X 轴交点 |
  | 拟合区间两端 | 空心圆 + 文字 `{百分比}% {荷载} kN`，**标在曲线上** | 曲线**上升段**与该荷载的交点（线性插值，`CurveDisplay.PointAtLoad`） |

  > 拟合区间两端这两点画在**实测曲线上**（它们是拟合区间的上下沿），**不是**画在修正直线上
  > —— 用户 2026-10-13 当天更正。曲线上升段没经过该荷载时（异常数据）才回落到修正直线上求交点。

- **量程口径**：**先 `AutoScale()`，再画标注**，标注**不参与**自动量程
  —— 修正直线在曲线尾部的延长值远高于峰值，参与量程会把曲线压扁。
- **两页共用** `Charts\CurveAnnotator.Draw`（试验执行页 + 历史数据页），两处必然一致；
  标注墨色取主题文字色 `CurveChartTheme.AnnotationColor()`，所以**换主题/换语言要整幅重画一次**。
- 参数表「启用曲线原点修正」**关掉就不画**直线与交点（判定器 `TangentK` = 0 → `CurveAnnotation.HasFit` 为 false），
  只留峰值点。
- **曲线首点按定义记在位移零点**（X = 0）：接触那一帧就是位移零点（现役同口径 `ActualDeformation := 0`）。
  2026-10-13 之前的库把首点记成了调零前的位移，回放时用 `CurveDisplay.ZeroFirstPointX` **只在显示上**抹平；
  库里与报表都用原始序列。
- 历史页与执行页的曲线都走同一套**显示抽稀 + 节流**口径（`CurveDownsampler`，绘图区像素宽 × 2 点封顶）。

## 导航栏（用户 2026-10-13）

- **折叠时鼠标悬停要能看到该项文字提示；展开时不弹**（展开时项上本来就有文字，气泡是多余的）。
- 做法：`NavigationView.IsPaneOpen` **双向绑定**到 `ShellViewModel.IsPaneOpen`；`OnIsPaneOpenChanged`
  与 `RebuildNavigation()` 末尾都调 `UpdateNavigationToolTips()` —— 折叠时把每项的 `ToolTip`
  设成 `Content`（当前语言的导航名），展开时清空。换语言会重建导航项，提示跟着换语言重新挂。
- **WPF-UI 自己不给折叠项挂提示**（实测：折叠后悬停无任何气泡）——这是本工程补的行为。
  以后加导航项**不用单独处理**，统一走 `UpdateNavigationToolTips()`。

## 弹出窗体（用户 2026-10-13）

- 以下三页以**模态弹窗**打开（不再换掉内容区）：**试验参数**（机器与控制参数）、
  **试验单**（新建试验单 / 选择已有试验单）、**试样信息填录**（新建试样 / 编辑试样）。
  入口都在试验执行页的按钮上。
- 弹窗外观：`Views\Dialogs\PageDialogWindow`（`FluentWindow` + `TitleBar` 只留"拖动 + 关闭 X"，
  无最大化/最小化）；**不重复写标题**，页面自己的大标题就是弹窗标题。
- 机制：`Services\ModalPageService.cs` 的 `IModalPageService.Show(pageType, width, height)`
  —— 从 DI 取页面 → 装进窗口 → `ShowDialog()`；返回 `true` = 页面给了「确定」。
- **页面只能用 `Frame`（或直接作 Window 内容）承接**：WPF 的 `Page` 只允许 Window / Frame 当父级，
  放进普通 `ContentPresenter` 会运行期抛"Page 只能具有 Window 或 Frame 父级"（已踩）。
- 页面 ↔ 宿主的对话：ViewModel 发 `IModalDialogViewModel.CloseRequested`；页面实现 `IModalPage`
  把事件转发出来（页面的 `DataContext` 是自己，宿主拿不到 ViewModel）；窗口据此设 `DialogResult`。
  **关窗时必须退订**（`Closed` 事件 + 关窗前各退一次）：ViewModel 是单例，不退订会在**第二次**弹窗关闭时
  对已关闭的窗口设 `DialogResult`，抛"只能在创建 Window 并且作为对话框显示之后才能设置 DialogResult"（已踩）。
- **弹窗不触发 `OnNavigatedTo`**：数据刷新统一走 `ViewModelBase.OnOpened()`（导航与弹窗两条路都会调），
  页面实现 `IModalPage.OnDialogOpened()` 转调它。参数页 / 试验单页都已改用 `OnOpened`。
- 尺寸按内容定：参数弹窗 **1340×800**（要并排放运行期 / 计算期两张 620 宽的卡，窄了 WrapPanel 会换行）；
  试验单弹窗 **780×640**；试样信息填录弹窗 **1060×620**。
- 参数页与试样页底部都补了「关闭」按钮（文案用 `Common.Close`；以前靠导航栏离开，弹窗里没有导航栏）。

## 试验执行页左栏（用户 2026-10-13）

- **试验单号**：标签与单号内容**同一行**显示（原来是上下两行）。
- **不写操作说明**：原来那段"每次启动试验跑一个试件…"的提示文字已删除（键 `Exec.SampleHint` 一并删掉）。
- **试样信息列表**：只列**当前试验单**的试样（换单/换页跟着换）。
  - 列表在左栏中部、自己滚动；列由**方法声明的试样信息字段**生成（`ITestExecution.SampleFields`，
    弯曲是 试件号 + 跨径 L / 试件宽度 b / 试件高度 h），所以列在 code-behind 里建（`BuildSampleColumns`），
    单元格是 `string[]` 按列序绑定。
  - 数据来源 `ITestExecution.ReadSampleRowsAsync(sheetId)`；按序号排（`SheetIndex`，老记录该列为空则从试件号解析）。
  - 刷新时点：进页面（`OnOpened`）、换单（当前试验单上下文变化）、**试样弹窗关闭后**、一件跑完落库后、自动建单后。
  - **当前试验单的口径**：优先"试验单弹窗里选定的单"（`ICurrentSheetContext`），其次才是本页自动建的那张
    —— 只认后者会导致"选了已有单，列表却空着"（2026-10-13 实测踩到）。
- **按钮可用性**（用户 2026-10-13，同日修订三次）：

  | 条件 | 启动试验 | 新建试样 | 编辑试样 | 删除试样 |
  | --- | --- | --- | --- | --- |
  | 试验单号为空（刚打开软件） | 置灰 | 置灰 | 置灰 | 置灰 |
  | 试样信息列表里没有数据 | 置灰 | 置灰 | 置灰 | 置灰 |
  | 有数据、但**没选中**任何行 | 可用 | 可用 | 可用 | 置灰 |
  | 选中的那件已"完成试验" | **置灰** | 可用 | **置灰** | 可用 |

  实现：`TestExecutionViewModel.CanAddSample`（单号非空 + 列表非空）、
  `CanEditSample` / `CanStartTest`（= `CanAddSample` && 选中件未完成）、
  `CanDeleteSample`（= `CanAddSample` && 选中了一行），分别做对应命令的 `CanExecute`；
  列表选中项（`SelectedSample`）、单号（`SheetText`）、列表内容变化时都 `NotifyCanExecuteChanged`。
  **启动/停止按钮例外**：试验中一律可用（`CanStartOrStop = IsRunning || CanStartTest`），
  否则跑起来就停不下来（2026-10-12 真机踩过）。
  "完成试验"= 明细行 `TestStatus` = **2**（现役枚举 `tsNotTested=0, tsTesting=1, tsCompleted=2, tsFailed=3`），
  试件跑完判定落库时写入（`BendingExecution`）。**老数据这一列是空的 → 不算完成**，仍可编辑。
- **删除试样**（用户 2026-10-13 要求真做）：先弹确认框（提示曲线 / 判定值 / 试样信息一起删、不能撤销），
  确认后按 `(SheetID, SampleID)` 删明细行（现役 `DeleteRecord(SheetID, SampleID)` 同口径），再刷新列表。
  删不存在的件不报错、只记一行"没找到这件试样"。
- **编辑试样 = 编辑选中那件**（选中哪件改哪件）；新建试样 = 弹窗自带下一个试件号；
  删除试样 = 删选中那件。

### 运行指示动画（用户 2026-10-13）

- 位置：**「启动试验」与「有效性计算」之间**，做成一个 **60×64 的指示框**（`Border` 圆角 + 主题描边），
  **与两侧按钮等高（64）、左右等距（各 16）**；框里是 `ArrowSync24` 图标（FontSize 28）。
  ⚠ 对不齐的坑：WPF-UI 的 `ui:Button` 默认**带外边距**，会让左侧按钮与框之间的间隙多出几像素 ——
  给「启动/停止」按钮显式写 `Margin="0"` 并 `HorizontalAlignment="Stretch"` 之后才真正等距
  （实测 20px / 20px）。
- 行为：**试验过程中转、其它时候停住**。开关在 `TestExecutionPage.xaml.cs` 里按 `ViewModel.IsRunning` 控制 ——
  `BeginAnimation(AngleProperty, 动画)` 开、`BeginAnimation(AngleProperty, null)` **真正停掉**（摘掉动画时钟、
  角度复位 0，不是暂停）；离开页面也停（`Unloaded`），回到页面按当前状态对齐（`Loaded`）。
- 提示文字：**试验中"试验进行中"、否则"待机中"**（`RunningHintText`，鼠标悬停在框上显示）。
- 颜色：试验中 `SystemFillColorSuccessBrush`（成功绿），待机 `TextFillColorSecondaryBrush`（次级文字色）
  —— `ViewModel.RunningBrush`，两个键都是工程里已在用的主题资源键。
- ⚠ **XAML 语法坑**：`ui:SymbolIcon` 元素自己的 `Symbol` 属性要写**枚举名字符串**（`Symbol="ArrowSync24"`）；
  `{ui:SymbolIcon X}` 这个**标记扩展**只用于 `Icon=` 这类 `IconElement` 类型属性（它返回的是控件实例）。
  把它写到 `Symbol=` 上会在解析 XAML 时抛 `ArgumentException: "Wpf.Ui.Controls.SymbolIcon" 不是属性 "Symbol" 的有效值`
  → **整页加载失败**（2026-10-13 实际踩过，用户截图报错）。

> **⚠ 已知死角（2026-10-13 提出，待用户定）**：按上面这张表，"试验单里一件试样都没有"时
> **新建试样与启动试验同时置灰** —— 于是新建一张空试验单之后**什么都点不了**，第一件试样无从产生。
> 建议二选一放开：① 空列表时允许**新建试样**（先填试样信息 → 再启动试验），或
> ② 空列表时允许**启动试验**（跑完一件列表就有数据了）。两条都能打开死结，选哪条取决于现场习惯。
- **列表滚轮**：页内列表都是 `DataGrid` / `ListBox`，**自带鼠标滚轮滚动**（`PageViewportFitter`
  已限制页面高度，所以滚轮不会被外层页面抢走）。实测：历史数据页试验单列表（31 行）、
  试验单弹窗列表（31 行）滚轮前后可见行都变了。**列表内容不足一屏时滚轮当然没反应** —— 那不是故障。
