## 环境坑（本机实测）

- `dotnet` 的 `DOTNET_CLI_HOME` 与 `-m:1` 两条，见上。
- **沙箱内查计划任务会假阴性**：`schtasks /query` / `Get-ScheduledTask` 报"找不到指定路径"，要在沙箱外查。
- 本机只有 `FlexCel.dll`、没有 `FlexCel.Render` → 不能把 xlsx 渲染成图做肉眼验证；
  读现役 xlsx 最可靠的办法是**把它当 zip 读**（`xl/worksheets/sheet1.xml` + `sharedStrings.xml` + `mergeCells` + `cols`），
  格式（粗体/对齐/边框）用 FlexCel 的 `GetCellVisibleFormatDef` 读。
- 本机模型走 **DeepSeek**（`api.deepseek.com`，API Key 模式，配置在 `C:\Users\ChenJie\.codex\config.toml`）。
  **侧栏一直显示"正在重新连接"是长期噪音**：没登录 ChatGPT，云端 durable 主机每 20 秒重试一次、注定失败，与本机干活无关。
- **别让单个会话上下文涨太大**：上一段对话单次请求 84.8 万 token（占 1M 窗口的 85%），最后三轮整轮零输出、
