## 四、与现役土工三轴库的结构性差异（避免误抄）

- 现役（GB/T 50123 土工体系）有饱和 / 固结 / 孔压全过程 → `SaturationBackPressure`、`ConsolidationProcess`
  两族过程表，以及 `PorePressure` / `PorePressureCoefficientB` / `SaturationMethod` 等字段。
- 本方法（T 1236）**无饱和、无固结、无孔压**：只有「施加围压 → 排水剪切」一条过程线，
  过程数据存曲线 JSON（`ChartData`）。
- 现役"完成"是**试件级**（`ExperimentCompleted`），主表没有完成时间；本设计沿用框架的
  `CompletedOn`（整单收尾）+ 明细 `TestStatus`（件级）。

## 五、待办与待定（2026-10-16 记录，持续更新）

1. **控制层"停止 / 破坏判据"接缝**：0.5mm 增量 < 5kPa / 轴向变形 15% 两条判据要做成方法级接口
   （现有 `TestRunProfile` 是弯曲口径的 BreakDrop 等字段，套不上）。推荐：新增方法可插的判据接口。
2. **方法代号**：是否由 `ShearStrength` 改用规范条号 `T1236`（改动会连带测试、资源键与模板主键）。
3. **SSR / τmax**：算法已就绪（`ShearStrengthAnalyzer.ShearStrengthRatio`）；界面与报表是否本期接入
   （规范原文"必要时"）。
4. **协议映射**：土工通讯规约 V1.7 的 C2 / A2 命令与「围压设置 / 轴向加载 / 0.5mm 采样」的对照表。
5. **报表**：按报告 6.1~6.8 立栏目（中英两套，版式照现役报表样式）。
6. **过程数据形态**：曲线 JSON vs 现役式过程表（与云端兼容的决策点）。
7. **方法参数声明**：围压级别 / 每级件数 / 应变速率（1~2 %/min）/ 判据阈值 / 试件尺寸合格窗，
   连同 T 1227 成型参数，落参数配置页声明。
8. **采集口径**：设备原始帧（宽约 190Hz）与"每 0.5mm 记录一条"的存取策略（建议存原始、导出按 0.5mm 抽样）。
9. **试件直径要求数值**：本扫描件只给"上 / 中 / 下各测 3 次"，具体直径及成型要求见 T 1227；
   需要 T 1227 文本或用户给定后才能把默认值与校验写死。
