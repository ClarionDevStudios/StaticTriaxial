## 保留的差异（有意）

1. **表名**：`BendingTestMain` 而非 `AsphaltBendingTestMain` —— 新库不与现役库兼容、不做迁移（既定决策）。
2. **数值类型**：现役数值列一律 `VARCHAR(10)`（读时靠 `NumField` 兜空串），新工程一律 `INTEGER` / `REAL`。
3. **跨度归属**：`SpanLength` 在主表与明细都存在（明细可覆盖），现役只在明细。

## 标识口径（与现役对齐，用户 2026-10-13）

**UUID**：建单时主表生成 `RecordUuid.New()`（标准 GUID 文本、大写、带连字符、无花括号，
与现役 `GenerateCleanGUID` 同格式）；**试样明细沿用所属试验单的 UUID**
—— 现役 `uBendingTestForm.pas:836` `FRecAsphaltBendingTestDetailInfo.UUID := FRecAsphaltBendingTestMain.UUID` 同口径。
用途是上传云端时按 UUID 去重，防同号单重复入库；主表 UUID 为空的老记录在追加试样时**自愈**（补一个并写回主表）。

**明细主键 = `(SheetID, SampleID)` 复合键**：原先自造的 `SampleKey` 单列主键**已删除**。
按件读写（读明细 / 读曲线 / 更新结果 / 判有效）一律用这两个条件定位，与现役
`GetRecord / DeleteRecord / GetChartData / UpdateChartData(ASheetID, ASampleID)` 一致。

**试件号 = `S` + 三位序号**（`S001`、`S002`…）：序号取该单已有的 `MAX(SheetIndex) + 1`（单里还没试件时为 1），
与现役 `GetMaxSampleIndex` + `SampleID := 'S' + FormatFloat('000', SheetIndex)` 一致；
序号同时写进 `SheetIndex`；老记录的纯数字试件号也认得（回退解析），接着往后排。
