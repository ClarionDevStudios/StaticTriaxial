## 一、帧格式（全协议通稿）

`FA FB FC` + 帧长度（1B，不含头与长度本身）+ 指令符（1B，A0-BF 上行 / C0-DF 下行）+ 有效数据（≤256B）+ CRC-8（1B，多项式 `0xD5`，对**长度+指令+数据**计算）。

## 二、三轴（GR-1）命令总表

### 下行（PC → GR-1）

| 指令 | 格式要点 | 用途 / 关键字段 |
| --- | --- | --- |
| `C0` 联机 | `… 04 C0 ORDER Par1 CRC` | `O,1`=返回一次 A0 后进入联机模式；`O,2`=联机下**主动回送** A1 |
| `C1` 电机加载 | `… 05 C1 Order1 Speed CRC` | Order1：0 停 / 1 正转（上升）/ 2 反转（下降）；Speed：2B，单位 **0.001mm/min**（文档 "0-10m" 系笔误——用户 2026-10-16 确认；现役 2400 = 2.4mm/min）。换向规矩：同向只改速、反向先停后反转 |
| `C2` 围压 / 反压（自动模式） | `… N C2 DATALIST CRC` | 围压目标 `WYPOINT`(4B, **kPa**)、反压目标 `FYPOINT`(4B, kPa)、启停 `WYTEST/FYTEST`(各 1B)、围压速度 `WYSPEED`(2B, 0.1mm/min, 1~500)、反压速度 `SYSPEED`(2B)、稳压速度 `CONTSPEED`(2B, 1~100)、加载杆面积（**4B**，按现役；说明里的"2 字节"判笔误） |
| `C3` 试验状态控制 | `… 04 C3 ORDER Par1 CRC` | `T,1`=试验状态 / `T,0`=停止 / `T,2`=饱和过程；`S,0/1/2`=抽气/水头/反压饱和（饱和仅 CU/CD 类用，T1236 用不上） |

### 上行（GR-1 → PC）

| 指令 | 关键字段 |
| --- | --- |
| `A0` 系统配置 | 硬件 / 固件 / 规约版本；PRESS1/2、Displacement1/2 的**量程、小数位、单位**；千分表 1-4 有效位；PRESS3/4/5（围压 / 反压 / 孔压）有效位 |
| `A1` 实时数据 | Press1/2（4B 有符号，按 A0 小数位）、Displacement1/2（4B）、Displacement3-6（2B，0.001mm）；**PRESS3 围压 / PRESS4 反压 / PRESS5 孔压（2B，0.001MPa）**；`SATAE`(4B) 围压系统状态位（加载/卸载/限位/超限/稳压）；`Main Status`(1B)（过载/位移限位/正反转）；`Test Status`(1B)；**V1.7 新增：围压体变 / 反压体变 / 主机体变 / 排水量（各 4B，有符号 3 位小数，ml）**；Data1/2 预留 |
| `A2` 应答 | `… 03 A2 ORDER CRC`：0 校验失败 / 1 执行成功 / 2 无法执行 |

## 三、语义映射（框架 ↔ 协议）

| 框架动作（ITestDeviceController / 运行链） | 协议实现 | 备注 |
| --- | --- | --- |
| `ConnectAsync` | `C0(O,1)` 等 `A0` → `C0(O,2)` 进入主动推送 | 联机前控制器不主动发数据（主从式） |
| `SetSpeedAsync` | `C1(Order1=同向, Speed)` | 同向运转只改速度；反向必须先停后反转（与现役/既有红线一致） |
| `StartAsync` | 先 `C3('T',1)`，再 `C1(Order1=1, Speed=试验速率)`（用户 2026-10-16 定：**C3 先于 C1**） | 试验速率 = 应变速率 × h0（T1236：1~2 %/min） |
| `StopAsync` | `C1(Order1=0)` → `C3('T',0)`（默认顺序，真机对一次） | 判据说停 → 停电机；**T1236 分段流程**（2026-10-16）：剪切段停止后再发 `C2 全 0` 卸围压（失败只记一条）——顺序真机对一次 |
| `JogAsync(Up/Down)` | `C1(Order1=1/2, Speed=JogSpeed)` | 按住运行 / 松开停止由界面驱动（现有语义） |
| `ReturnToStartAsync` | `C1(Order1=2, Speed=试验速率)`，走够时长由调用方停 | 与现役 `tpAutoReset` 口径待对照 |
| `ZeroDisplacementAsync` | **无对应下行**——按既定口径做**上位机软件调零（存偏移量）** | 5.x 没有"清零"指令（与 GR-3 的 C3H 不同） |
| **围压 / 反压施加**（T1236 第一步） | `C2`（目标 + 启停 + 速度 + 稳压速度 + 加载杆面积） | **【已落地 2026-10-16】** 可选接口 `IConfiningPressureControl`（施加 `ApplyConfiningPressureAsync(σ3)` / 卸除 `ReleaseConfiningPressureAsync`）；`GeoDeviceController` = **单发一条 C2、等 A2 即返回**（稳压由下位机完成）；`SwitchableDeviceController` 转发给当前来源、来源不支持就明确报错。**执行页分段流程已接**（「施加围压」按钮 → 围压/稳压指示随 A1 刷新 → 「开始剪切」） |
| 实时采样 `SampleReceived` | `A1` 每帧解析 → `TestSample` | 映射：轴向力 ← Press1（按 A0 换算）；轴向位移 ← Displacement1（0.001mm）；围压 ← PRESS3；状态位 ← `Main Status` / `SATAE` |
| 每 0.5mm 采样（T1236 4.5/4.6） | A1 原始流 → 控制层按**位移增量 ≥0.5mm** 抽点记曲线 | 口径定案（用户 2026-10-16）：存原始帧、导出 / 落库按 0.5mm 抽样；抽点工具 `ShearStrengthAnalyzer.SampleAtInterval` 已落地 + 2 条用例 |
| 命令应答 / 超时重发 | `A2`（1=成功） | 可复用 IAP `CommandChannel` 的超时重发模式 |

## 四、口径已定（2026-10-16 用户答复）与真机待对项

1. **`C1 Speed`**：文档"0-10m，精度 0.001mm/min"**系笔误**——按现役实测口径 **0.001mm/min** 实现
   （现役 2400 = 2.4mm/min）。默认速率 = 1.5%/min × 306mm ≈ **4.59mm/min**，落在规范 2.1.2 的
   设备窗（0~5mm/min）内。**真机对一次**实际速率窗（只剩这一项）。
2. **`C2` 目标值单位**：按 **kPa** 实现（现役同口径），真机对一次；`Loading rod diameter` 按现役
   **4 字节**实现（说明"2 字节"判笔误）。
3. **`C3` 启用时机**：**先于 C1 发送**——开始：`C3('T',1)` → `C1(启动)`；停止默认 `C1(停)` →
   `C3('T',0)`（真机对一次）。
4. **`A1 Press2`**：**预留**（用户定）；千分表 3-6 的有效位与量程换算真机对一次。
5. **体变四字段**：先解析（已实现），**入库与否后定**（不阻塞）。
6. **CRC-8 校核**：**已完成**——运行期生成表与现役 `uCrc8Code.pas` 256 项逐项一致；
   现役算法黄金向量（C0=0x6E / C1(2400)=0x21 / C3=0xCB / C2=0xB6 / A2=0x8D）全部锁进用例；
   真机帧到位后补实帧用例。

7. **A1 换算**：**已对照现役**（`uDataProcessingController.pas`：值 = raw / 10^Digits；
   `GetAxialPressure = kN ÷ 面积(cm²) ×10⁴ = kPa`，与判定器 σ 公式同源）；真机只需验一遍量程与符号。

8. **围压口径**（用户 2026-10-16）：**施加 = 单发一条 C2，稳压由下位机完成** —— 上位机不做调节循环、
   不等待（要显示就轮询 A1 的 `SATAE` 稳压位，不阻塞）。参数照现役 `土工三轴软件通讯重构版`
   调用口径（`uMainForm.pas:991`）：`WYSPEED=400`（40.0mm/min）、`CONTSPEED=50`（5.0mm/min）、
   **反压不启用**（现役同帧传 `1/1`——真机对一次，若固件要求反压泵同启，改一处传参）；
   加载杆面积是**设置项**（现役 INI `config\LoadingRodArea`，原始值 = cm²×1000；
   黄金向量口径 19.635cm² → 19635，**真机对一次**）。卸除围压 = 现役同帧 `C2(0,0,0,0,0,0,0, 面积)`。
