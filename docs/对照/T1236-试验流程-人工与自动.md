## 二、待定项（需要拍板；都附了推荐）

**Q1 分段触发还是全自动？【已确认：取 (a)】**

- **(a) 分三段（推荐）**：①"施加围压"按钮（发 C2）→ 看稳压指示 → ②"开始剪切"按钮
  （内部先**位移调零**、再 C3→C1 起判据）。另保留一个独立"位移调零"按钮（现役也有）。
  接触段（#7）结束后电机自动停住等"施加围压"。
- (b) 全自动：点"开始接触"后 接触 → 停 → 发 C2 → 检测稳压位 → 自动调零 → 自动剪切。
- 推荐 (a) 的理由：规范把"稳压 → 调零 → 剪切"排成有序步骤，且 #8 同时要求人工开排水管 /
  卸真空——全自动会在人工还没弄完时就开剪；现役也是按钮式。

**Q2 "卸除围压"的触发？【已确认：取 (a)】**

- **(a) 本轮停止时自动卸（推荐）**：判据停机 或 手动停止 → C1 停 → C2 全 0 → C3('T',0)
  （现役"停止剪切"即此款）；另留一个"卸除围压"手动按钮给异常兜底。
- (b) 只留手动按钮，操作员按了才卸。
- 推荐 (a)：围压 30~100kPa 不高，停机时释放最稳妥、也跟现役一致；拆室前操作员仍可再点按钮确认。

**Q3 试验后数据（4.7：质量 / 含水率 / 干密度 / 含水率损失）从哪里录？【已确认：补录按钮】**

用户口径：**增加一个「补录」按钮** —— 打开试样信息编辑窗的补录模式，**仅录入试验后数值**
（质量 / 含水率 / 干密度 / 含水率损失），**原有试样参数只读**，**带合法性校验**。

**Q4 接触段（#7）结束后的行为确认？【已确认】**

规范明文：接触 3~5kPa 之后才施加围压（4.3 → 4.4）。所以软件在接触达成后**不能**顺势
切换到试验速率、直接拉曲线，而是停在"等施加围压"。这一条会改执行页现流程（现框架是一键连跑）。

**Q5 尺寸合格窗的校验强度？【已确认：警告不硬拦】**

306±5mm 是规范明文；建议：超窗时**界面警告但允许继续**（记录真实数据），不做硬拦；
缺尺寸（根本没填）则**硬拦**（已按设计文档待办①实现：开始试验前报"先去填试样信息"）。
