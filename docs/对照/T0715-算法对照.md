## 一致的部分

| 项 | 口径 |
| --- | --- |
| 5.3 弯曲强度 | `R_B = 3·L·P_B / (2·b·h²)`，P_B 以 N 计，结果精确至 0.01MPa |
| 5.4 最大弯拉应变 | `ε_B = 6·h·d / L²`，结果精确至 0.1με |

## 分歧点（ANX 有意不同，或需要规范确认）

| # | 项 | 现役做法 | ANX 做法 | 理由 |
| --- | --- | --- | --- | --- |
| 1 | 几何参数非法（L/b/h ≤ 0） | 返回 **0.0** | **抛 `ArgumentOutOfRangeException`** | 返回 0 会把"参数没填"伪装成正常结果，还会混进一组平均值里；入口挡一次更安全（见 [[踩坑合集]] 的"算式参数为 0 会静默得到 Infinity"） |
| 2 | 结果舍入 | `SimpleRoundTo(…, -2)` 直接用 | 先用 `RoundTo` **吃掉浮点噪声**再按精度舍入 | 实测踩到：交点算出来恰好是 4.75mm，二进制浮点得到 4.749999…，直接舍入成 4.7（错），ANX 得 4.8（对） |
| 3 | 组统计与超差剔除（5.5 / 5.6：允许误差 400με，超差剔除偏差最大者后重算） | 在 DAO/界面层做 | **本步未做**，留到 M3 第 3 步（要跟数据表一起落地） | — |
| 4 | 1.5mm 偏移量与 10%~80% 回退区间 | 硬编码常量 | 同样取 1.5 / 10%~80%，但**标为「出处待规范确认」** | 规范 PDF（`E:\规范文档\…弯曲试验.pdf`）本机**没有 PDF 文本工具**（pypdf / pdfplumber / pymupdf 均未安装，安装需联网），这两条目前只能从现役反推。**需要时把规范 5.1/5.2/6.1/6.2 的原文贴给我，即可闭环** |

### 两条重大更正

1. **「1.5mm 偏移线」已从弯曲试验中抛弃**。规范 5.1~5.6 通篇没有它 —— 那是**稳定度（马歇尔）试验**的内容，
   现役把它误抄进了弯曲分析器（该文件头自述"从 SplittingTestAnalyzer 抄写"）。
   因此 ANX 的弯曲判定**只有一条路径**：取曲线最大荷载作为 P_B。`BendingPeakMode` / `AnalyzeNonObviousPeak` 相关代码已删除。
2. **修正直线的拟合方法属"实现选择"，不是规范要求**。规范 5.1 只说"进行原点修正"，未规定怎么拟合。
   ANX 按用户决定**沿用现役口径**（平滑窗口 5 → 滑窗 R²≥0.99 → 回退峰值 10%~80% → 3σ 剔除重拟合），
   并在代码注释里标注为可替换的实现选择。

用例数从 7 降到 **6**（删掉 6.2 那条）；测试总数 **60/60 通过**。
