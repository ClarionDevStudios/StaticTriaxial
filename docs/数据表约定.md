# ANX 方法数据表约定

> 记录**表结构**上的硬规则，新增试验方法（马歇尔、车辙…）时照做。每条注明来源日期。

## 1. 字段名与现役一致（用户 2026-10-13）

**新增方法的数据表，字段名必须与现役软件同名**（现役 = `E:\Work\沥青力学试验软件`；
对照源是它的建表 SQL 与 DAO 里的字段记录类型 `T<方法>*Info`）。

**类型可以不同**：现役数值列一律 `VARCHAR(10)`（读时靠 `NumField` 兜空串），
ANX 用真实类型 `INTEGER` / `REAL` —— 这一条是**有意保留**的差异（真数字比字符串好维护）。

为什么：数据最终要上传云端数据库并与现役数据并存，字段名一致才能直接对接、才能用现役的表结构
读懂我们的数据；自造字段名（如曾经那个 `SampleKey`）等于给自己挖隔离带。

**例外只有两类，且必须在对照笔记里写明**：

1. **表名**：ANX 用 `BendingTestMain` 这类名字，不叫现役的 `AsphaltBendingTestMain`
   —— 新库不与现役库共库、不做迁移（既定决策）。
2. **纯新增列**：现役没有、我们确实需要的列（如 `InvalidReason`）。新增列要能在现役里找到"对应物的落点"，
   并在 `docs\对照\<方法>-字段对照.md` 里标出来。

## 2. 标识口径（用户 2026-10-13）

| 项 | 口径 | 现役出处 |
| --- | --- | --- |
| 单号 `SheetID` | `前缀 + yyyyMMdd + 3 位流水`（沿用现役规则） | 单号生成器 |
| 试件号 `SampleID` | `S` + 三位序号（`S001`），序号 = 该单 `MAX(SheetIndex) + 1` | `GetMaxSampleIndex` + `'S' + FormatFloat('000', SheetIndex)` |
| 排序 `SheetIndex` | 与试件号里的序号同一个数（写入时自动回填） | 同上 |
| `UUID` | 建单时主表生成（GUID 文本、大写、带连字符、无花括号）；**明细沿用所属单的 UUID** | `GenerateCleanGUID`；`Detail.UUID := Main.UUID` |

用途：上传云端按 `UUID` 去重、按 `(SheetID, SampleID)` 定位一件试样。

## 3. 明细表主键

**`(SheetID, SampleID)` 复合键**，不要再自造单列主键。
框架侧就是 `TableDefinition` 的 `PrimaryKeyColumns`（列表）—— 下单列、明细两列。

## 4. 每列都要有中文含义注释

`ColumnDefinition` 的第 4 个参数（`Comment`）写清单位与取值口径，
`SchemaBuilder` 会把注释写进建表 SQL；`docs\对照\建表SQL.sql` 由 `ANX.Tools.SchemaDump` 生成，别手改。

## 5. 迁移：不做自动迁移

`DatabaseInitializer` 只在表不存在时建表、只校验架构版本号，**不改动已有表**。
字段增删由人工执行 SQL（改完记得同步 `SchemaBuilder.CurrentSchemaVersion`）。
