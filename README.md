## 工程划分

```
src\ANX.Core     领域与契约（无外部引用）
src\ANX.Ui       WPF 外壳与通用页
src\ANX.Host     宿主（唯一引用 methods\ 的工程）
tests\            xUnit
methods\          方法插件（M3 起）
docs\             实现方案、对照表、学习笔记
```

**依赖铁律**：Core 不引用任何业务工程；Ui 只认 Core 的接口；Host 是唯一引用 `methods\*` 的工程；方法工程可引用 Core、不得引用 Ui。
